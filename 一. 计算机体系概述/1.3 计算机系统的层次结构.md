# 一、计算机系统抽象层的转换

## 计算机系统的大致架构

![[c_os_architecture.png]]

- **多层转换总路径**：应用问题最初以自然语言描述，需依次经过算法抽象、高级语言程序设计、高级语言转机器语言目标程序等多层转换，最终成为计算机硬件可识别、可执行的机器语言程序。
- **开发与运行的支撑体系**：高级语言程序开发依托**集成开发环境（IDE，即语言处理系统）**，它集成了程序编辑器，以及预处理、编译、汇编、链接等全套翻译转换工具；程序运行所需的图形 / 命令行交互界面、底层系统调用服务，则由**操作系统（OS）** 提供。操作系统是对计算机硬件与底层结构的抽象，所有语言处理系统都运行在操作系统平台之上。
- **软硬件的核心接口：ISA**：**指令集体系结构（ISA，又称指令系统）** 是软件与硬件之间的桥梁与接口规范，它定义了计算机可执行的全部指令集合，明确了每条指令的操作类型、操作数的地址空间与数据类型。机器语言程序本质是符合 ISA 规范的指令序列，硬件执行程序的过程就是逐条执行指令的过程。
- **ISA 与微架构的分层关系**：**微架构（又称计算机组织）** 是 ISA 的电路逻辑实现，二者属于完全不同的层面：ISA 定义 “提供什么功能 / 指令”（如是否包含加法指令），微架构决定 “功能如何用电路实现”（如加法器采用串行进位还是并行进位）。同一种 ISA 可对应多种不同的微架构，只要 ISA 兼容，不同微架构的处理器便可运行相同的程序。
- **硬件的底层落地**：微架构中的功能部件由逻辑电路实现，不同的逻辑实现方案会带来性能与成本的差异，而基础逻辑电路最终通过具体的器件技术落地实现
# 二、计算机系统的不同用户
1. **计算机系统基本构成**
    计算机系统由硬件和软件两部分组成，所有任务都通过执行程序包含的指令完成。硬件是芯片、板卡、外设等物理装置的总称；软件包含运行在硬件上的程序、数据及相关文档，其中程序是指挥计算机操作的指令序列，数据是指令的处理对象。
2. **软件的两大分类**
- **系统软件**：介于硬件与应用程序之间，与具体应用关联度低，核心作用是管理计算机资源、支撑应用软件的开发与运行。主要包括操作系统（负责资源管理、提供人机交互界面与应用支撑）、语言处理系统（提供高级语言编程的编辑、翻译、调试等全流程环境）、数据库管理系统，以及磁盘整理、数据备份等实用程序。
- **应用软件**：面向数据处理、科学计算、办公、多媒体等具体应用场景编写，用于满足特定领域的使用需求，常见的文字处理软件、多媒体播放器、游戏、炒股软件等都属于此类。
3. **四类计算机用户定位**
- **最终用户**：使用应用软件完成特定任务的人群，是最广泛的计算机使用者。
- **系统管理员**：依托操作系统、数据库等系统软件，负责系统的配置、管理与维护，具体包括软硬件安装升级、用户账户管理、数据备份与恢复等工作，目标是搭建高效可用的系统环境。
- **应用程序员**：使用高级编程语言开发应用软件的开发人员。
- **系统程序员**：专注于设计开发操作系统、编译器、数据库管理系统等系统软件的开发人员。
